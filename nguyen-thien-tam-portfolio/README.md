# Portfolio cá nhân – Nguyễn Thiện Tâm

Website Portfolio tĩnh được xây dựng bằng HTML, CSS và JavaScript.

## Cách xem
Mở `index.html` trên trình duyệt.

## Cách đăng lên GitHub Pages
1. Tạo repository công khai trên GitHub.
2. Tải toàn bộ nội dung thư mục này lên repository (giữ nguyên thư mục `assets`).
3. Vào Settings → Pages.
4. Chọn Deploy from a branch → `main` → `/(root)` → Save.
5. Đợi GitHub Pages xuất bản website.

## Cập nhật sản phẩm bài tập
Trong `index.html`, tìm phần `project-list`. Thay các liên kết đang dẫn tới `#contact` bằng đường dẫn bài tập thật khi bạn đã tải bài lên.

Thông tin được biên soạn từ tài liệu cá nhân do người dùng cung cấp.
